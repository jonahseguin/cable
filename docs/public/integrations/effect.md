---
title: Effect integration status
description: Cable's private Effect integration targets Effect version 4 release candidate 112 and provides wrappers for procedures, channel handlers, and client streams.
---

`@cable/effect` targets `effect` `4.0.0-rc.112`. It remains private and unpublished, so it is not a stable package release.

The package provides Effect wrappers for Cable procedures, channel handlers, and client streams. Its core package does not add an Effect dependency.
