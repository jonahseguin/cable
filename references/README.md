# Research references

The implementation draws on established open-source projects. Their source is
not vendored in this repository; consult the upstream projects directly and
follow each project's license when adapting an idea or implementation.

- [tRPC](https://github.com/trpc/trpc) — contract-shaped procedures and client ergonomics (MIT).
- [oRPC](https://github.com/unnoq/orpc) — contract-first APIs and Standard Schema integration (MIT).
- [Effect](https://github.com/Effect-TS/effect) — typed errors and resource ownership (MIT).
- [Cloudflare Agents](https://github.com/cloudflare/agents) — Durable Object lifecycle patterns (MIT).
- [PartyServer](https://github.com/cloudflare/partykit/tree/main/packages/partyserver) — WebSocket hosting patterns (ISC).
- [Cap'n Web](https://github.com/cloudflare/capnweb) — object-capability RPC patterns (MIT).

The public [acknowledgements](../docs/public/acknowledgements.md) page records
the direct influences on cable's API and runtime design.
